# MinifyJS documentation

This directory contains the documentation for MinifyJS. Everything
is written in Markdown and rendered as-is on GitHub or by any static
site generator.

## Where to start

- **New to MinifyJS?** Start with [getting-started/quickstart.md](getting-started/quickstart.md).
- **Installing?** See [getting-started/installation.md](getting-started/installation.md).
- **Using the CLI?** See [cli/overview.md](cli/overview.md).
- **Using the Python API?** See [python/api.md](python/api.md).
- **Curious how it works?** See [architecture.md](architecture.md).
- **Contributing?** See [development/setup.md](development/setup.md).

## The layout

| Directory | What lives there |
|---|---|
| `getting-started/` | Installation, quickstart, and a first project walkthrough |
| `cli/` | Command-line reference: every flag, every behavior |
| `Go/` | Go api reference every function,every type |
| `python/` | Python API reference: every function, every type |
| `engine/` | How MinifyJS wraps esbuild, and what that means |
| `integrations/` | Adapters for Flask, Django, FastAPI, and generic Python |
| `development/` | Setup, testing, benchmarking, release process |
| `reference/` | Configuration, error codes, exit codes, versioning |
| (top level) | Architecture, design principles, compatibility, security |

## The style

Documentation pages are:

- **Short.** A page that needs scrolling three times is two pages.
- **Concrete.** Every claim is followed by an example or a command
  the reader can run.
- **Honest.** When MinifyJS cannot do something, the docs say so
  plainly. Marketing language is out of scope.

## Generated files

A few files in `docs/` are generated and must not be edited by hand:

- `cli/reference.md` — generated by `tools/docs/generate_cli_reference.py`
- `supported-syntax.md` — generated by `tools/docs/generate_syntax_matrix.py`

Every generated file starts with a note saying so. If you need to
change one, change the source (the CLI's `--help` text or the
fixture `matrix.json` files) and regenerate.
